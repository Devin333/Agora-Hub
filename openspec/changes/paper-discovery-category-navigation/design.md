## Context

现有查询 API 和 queryPapers 已支持 method/task，发现页状态未传递。当前缓存论文的 methodRefs/taskRefs 为空，不能按标题猜测分类或引用静态示例计数。

## Goals / Non-Goals

**Goals:** 三组统一的 5 项预览/展开/收起，真实计数与筛选，已选条件可见，保留桌面紫色样式。

**Non-Goals:** 自动标注、分类后端重建、移动端适配。

用户追加范围：完全替换 `/papers/methods` 与 `/papers/tasks` 旧目录页面。两个页面沿用发现页的浅紫色视觉，提供方向导航、搜索、排序、分类详情和真实关联论文。详情在目录页内展开并写入 URL，不跳入旧版详情布局；既有外部详情链接保持可用，不在本次重建范围。

## Decisions

1. 服务端从已有 catalog 仅取分类标识、名称、方向和说明，与公开论文的 refs 合并；数量通过共享 queryPapers 匹配规则计算。无标注类别显示待标注并禁用论文筛选，但目录中的分类简介仍可打开。不继承 catalog 内的示例计数、趋势、论文或关系。未知的真实 refs 也收录。
2. 领域全部来自公开 tags，移除前 8 个截断；三组各显示 5 类。更多显示剩余数量，收起后选中项替换第五项，始终维持 5 个可见条目。
3. 分组标题使用 button、aria-expanded/controls；独立目录链接单独呈现。长侧栏使用 sticky + 有界滚动，名称换行，不使用省略号隐藏含义；键盘焦点可见。
4. method/task 是独立单选维度，与 q/topic/time/feature 条件求交。变更类别清除页码和预览，保留其他条件。URL 支持刷新和返回；筛选标签分别移除，重置一次清除所有筛选。
5. 两个独立目录共用一个展示组件。左侧方向默认显示 5 个，支持展开；右侧分类可搜索、按名称或真实关联数排序。分类详情保留目录上下文，相关论文可进入现有阅读器，全文检索入口明确标为关键词检索而非已确认分类。

## Risks / Trade-offs

- 当前方法/任务未标注 → 明确待标注和关联说明；UI 可完整浏览定义，筛选能力须等待真实 refs。
- 分类数为全库关联数，可能与组合结果不同 → 标明统计口径。
- 并行后端任务处于脏工作树 → 隔离执行必需 smoke，前端变化单独测试、构建和提交。
