## Why

论文发现页的研究方法、研究任务只有目录链接，用户无法直接查看类别并组合筛选。领域列表也被固定截断，侧栏缺少统一的展开、选中和清除反馈。

## What Changes

- 统一三组分类导航，每组默认显示 5 类，其余显式展开，可收起整组。
- 使用现有分类定义和真实论文关联计算数量，无关联标注时显示待标注而非伪造计数。
- 接通 method/task URL 条件、真实 API 与离线回退，保留其他筛选和阅读返回上下文。
- 可见选中项、可移除条件标签、明确全库统计口径和目录入口。
- 完全替换研究方法、研究任务的旧目录布局，提供一致的浅紫色桌面界面、方向导航、分类搜索与可恢复的页内详情。

## Capabilities

### New Capabilities
- `paper-discovery-category-navigation`: 论文发现页可展开分类和组合筛选。

### Modified Capabilities

无。

## Impact

frontend 论文发现页、方法与任务目录页、共享发现状态、阅读返回上下文和分类投影。不修改标注业务，不新增依赖。
